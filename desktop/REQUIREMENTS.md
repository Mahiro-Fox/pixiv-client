# Pixiv 下载器（桌面端）需求文档

- 文档版本：v1.0
- 对应代码：`desktop/`（Electron + React + TypeScript + Tailwind）
- 文档定位：描述当前已实现的功能范围与行为约定，用于验收、迭代与后续扩展对齐

---

## 1. 项目概述

一款运行在 Windows 桌面的 Pixiv 作品批量抓取与下载工具。用户配置作者 ID、标签、保存目录与 Cookie 后，可抓取该作者指定标签下的全部作品，在列表中选择需要的作品批量下载，并支持暂停、断点续传、失败重试与本地已下载判定。

区别于脚本版（仓库根目录的 Python 实现），桌面端提供图形界面、可视化进度、下载队列持久化，以及针对 pixiv 限流（429）的全局请求治理。

### 1.1 目标用户

- 需要批量备份某位画师作品的用户
- 需要按标签批量收集素材的用户
- 希望有图形界面、能中断续传，而不是命令行脚本的用户

### 1.2 技术形态

- Electron 45 主进程 + React 19 渲染进程，TypeScript
- 界面使用 Tailwind + 手写 shadcn/ui 风格组件
- 网络请求走 Electron `net` 模块，直接复用系统网络栈并注入 Cookie / UA / Referer
- 打包运行：开发模式 `npm run dev`，构建 `npm run build`

## 3. 功能需求

### 3.1 配置管理

**入口**：左侧抓取面板（组件 `CollectPanel`，只放爬取相关参数）；下载质量、保存目录、文件名模板、Cookie 等全局设置在顶栏「设置」按钮打开的设置弹窗（`SettingsDialog`）中。

**作品来源**

| 来源 | 说明 | 主要参数 |
| --- | --- | --- |
| 作者标签 | 抓取指定画师在指定标签下的作品 | 用户 ID、标签 |
| 我的收藏 | 同步某个账号的收藏夹 | 收藏用户 ID（留空使用当前登录账号）、收藏类型（公开/私密）、可选标签 |

**字段与约束**

| 字段 | 说明 | 取值范围 / 默认值 |
| --- | --- | --- |
| 用户 ID | pixiv 用户 ID（作者标签来源） | 数字字符串，默认 `114638697` |
| 收藏用户 ID | 收藏夹所属账号；留空则读取当前登录账号 | 数字字符串，默认空 |
| 收藏标签 | 收藏夹接口级标签过滤，留空表示全部 | 字符串，默认空 |
| 收藏类型 | 公开收藏 / 私密收藏 | `show` / `hide`，默认 `show` |
| 标签 | 作者标签来源的作品标签（作为主标签） | 字符串，默认 `R-18` |
| 附加包含标签 | 多标签组合的额外包含标签，逗号/空格/顿号分隔 | 字符串，默认空 |
| 排除标签 | 多标签组合中需要排除的标签 | 字符串，默认空 |
| 组合方式 | 多标签之间「同时满足（AND）」或「任一满足（OR）」 | `and` / `or`，默认 `and` |
| 起始偏移 | 从第几个作品开始抓取（用于跳过已处理部分） | ≥ 0，默认 0 |
| 每页数量 | 单次接口请求条数，同时作为作品列表的翻页步长 | 1–100，默认 48 |
| 并发数 | 同时解析/下载的任务数 | 1–32，默认 8 |
| 请求间隔（秒） | 每个任务开始前的额外等待，用于进一步降速 | 0–5，默认 0.2 |
| 下载质量 | 常规图（约 1200px）/ 高清原图（作品原始尺寸） | `regular` / `original`，默认 `regular` |
| 保存目录 | 下载根目录，必须是绝对路径 | 默认开发模式为 `../pixiv_downloads`，打包后为「下载/pixiv_downloads」 |
| 文件名模板 | 落盘文件名格式，支持 9 个变量 | 默认 `{id}_p{page}_{title}` |

**行为**

- 配置写入 `userData/config.json`；点击「抓取作品列表」或「下载选中作品」时会先保存当前表单值；关闭「设置」「过滤规则」弹窗时也会立即落盘。
- 下载质量可在左栏下载按钮上方与设置弹窗中切换，两处共用同一份配置。
- 任务快照会记录创建时的下载质量，断点续传时未解析的作品沿用该质量。
- 保存目录支持「选择目录」系统对话框与「打开目录」。
- 保存目录必须是绝对路径，否则下载前直接报错，不会开始任务。
- 保存目录下的子目录名：作者标签来源使用标签名，收藏夹来源固定为 `收藏夹`。

### 3.2 Cookie 管理

**入口**：顶栏「设置」弹窗中的 Cookie 区域，以及顶部 Cookie 状态徽标。

**需求**

- 支持粘贴 `PHPSESSID=...` 或完整 Cookie 字符串后保存。
- 只填 PHPSESSID 值时自动补全为 `PHPSESSID=...`；多行输入会合并为 `key=value; key=value` 形式。
- Cookie 来源优先级：环境变量 `PIXIV_COOKIE` > 用户数据目录的 `pixiv_cookie.txt` > 开发模式下的仓库根目录 `pixiv_cookie.txt`。
- 界面展示来源（环境变量/本地文件/未配置）与脱敏后的值。
- 配置 Cookie 后自动调用用户信息接口识别当前登录账号（昵称 + ID），用于收藏夹同步。
- 「下载选中作品」在未配置 Cookie 时禁用，因为未登录状态下 R-18 作品会被 pixiv 过滤。

### 3.3 作品抓取

**入口**：左侧「抓取作品列表」/「同步收藏夹」。

**需求**

- 作者标签来源：调用 pixiv 标签作品接口，按 `起始偏移`、`每页数量` 拉取首页，随后按总数补齐剩余分页。
- 收藏夹来源：调用收藏夹接口，按 `收藏用户 ID` + `收藏类型` 分页拉取；`收藏用户 ID` 留空时自动使用当前登录账号，未登录则报错提示。
- 收藏夹可按「收藏标签」过滤（接口级过滤，留空表示全部）。
- 抓取过程中显示：已抓取数量/总数（已完成页数/总页数）。
- 结果按作品 ID 去重，保持接口返回顺序。
- 分页级失败不阻断整体：记录失败页数，完成后提示「N 个分页抓取失败，列表可能不完整」。
- 抓取结果为空时提示检查来源参数（用户 ID / 收藏用户 / 收藏类型 / 标签 / Cookie）。
- 翻页并发最多 3 路，实际节奏由全局 API 限速闸门控制，降低 429 概率。
- 抓取会重置作品列表、清空预览、回到第 1 页，并重新扫描本地已下载状态。
- 默认选中「当前筛选结果第一页」的作品。

### 3.4 收藏夹同步（增量）

**入口**：作品来源切换到「我的收藏」后点击「同步收藏夹」。

**需求**

- 支持公开收藏与私密收藏；私密收藏需要有效 Cookie。
- 「只同步未下载的作品」默认开启：抓取完成后自动开启「只看未下载」筛选，列表只保留本地缺失或页数不全的作品，实现增量同步。
- 默认全选的对象是「按过滤规则 + 只看未下载筛选后的第一页」，因此一键下载即为新增内容。
- 收藏夹作品统一存放到 `{保存目录}/收藏夹/{作者ID}_{作者名}/`，不随收藏标签变化。
- 收藏夹来源下标签输入用于接口级过滤；作者标签来源下标签用于指定画师的作品标签。

### 3.5 过滤规则

**入口**：作品列表工具栏的「过滤」图标按钮（生效规则数量以徽标显示），点击打开独立弹窗。

**规则项**

| 规则 | 说明 | 默认 |
| --- | --- | --- |
| 最少页数 | 作品总页数下限，0 不限 | 0 |
| 最多页数 | 作品总页数上限，0 不限 | 0 |
| 最小宽度 | 原图宽度下限（接口未返回宽度时不参与判断），0 不限 | 0 |
| 最小高度 | 原图高度下限，0 不限 | 0 |
| 内容分级 | 全部 / 仅 R-18 / 排除 R-18 | 全部 |
| 排除 AI 作品 | 按接口的 AI 标记过滤 | 关闭 |
| 排除关键词 | 匹配标题与作者名，逗号/空格/顿号分隔，不区分大小写 | 空 |
| 排除标签 | 匹配作品标签，同时兜底匹配标题与作者名 | 空 |

**行为**

- 规则在本地对抓取结果实时生效（纯前端计算），不额外发起网络请求。
- 多条规则之间是「与」关系，任意一条不满足即排除。
- 列表顶部显示「规则过滤 N」的数量；过滤图标显示当前生效的规则条数；分页、全选、只看未下载均基于过滤后的结果。
- 配置随 `config.json` 持久化；弹窗底部「清空」可一键恢复默认，关闭弹窗即保存配置。
- 过滤器实现位于 `desktop/src/renderer/src/lib/filters.ts`。

### 3.6 作品列表与浏览

**入口**：右侧「作品列表」标签页。

**卡片信息**

- 缩略图（加载失败时隐藏图片并显示占位图标）
- 左上角勾选按钮（点击不触发详情）
- 右上角徽标组（纵向排列）：多图作品的页数、R-18（`xRestrict ≥ 1`）、AI（`aiType = 2`）
- 左下角「已下载」徽标（按严格页数校验判定）
- 标题（最多两行）与作者名

**交互**

- 点击卡片任意区域（勾选按钮除外）打开作品详情弹窗。
- 点击勾选框切换选中状态。
- 顶部统计：筛选后作品数、接口总数、规则过滤数、已下载数、已选数。
- 「只看未下载」开关：仅显示本地判定为未完整下载的作品；开启时回到第 1 页。
- 排序下拉：默认顺序 / 页数最多 / 页数最少 / 最新发布 / 最早发布；切换后回到第 1 页。
- 「导出」按钮：把当前筛选后的完整结果导出为 CSV 或 JSON（不限于当前页）。
- 「全选本页 / 取消全选」：只作用于当前页作品。
- 空状态区分两种情况：「还没有作品」与「没有未下载的作品」，后者提供「查看全部作品」。

### 3.6.1 结果排序与清单导出

**排序**

- 排序在过滤与「只看未下载」之后、分页之前执行，因此翻页与全选都以排序后的顺序为准。
- 默认顺序保留接口返回顺序；页数、发布时间排序为本地计算，不额外请求。
- 发布时间的空值或无法解析时按 0 处理，不会导致顺序错乱。

**清单导出**

- 导出范围是「当前过滤结果的全部作品」，而非当前页。
- 保存对话框支持 CSV 与 JSON 两种扩展名，按所选扩展名决定格式；默认文件名 `pixiv-works-{标签}-{时间戳}`，默认目录为系统「下载」。
- 列：作品ID、标题、作者ID、作者、页数、宽、高、分级（R-18）、AI、发布时间、标签、已下载、作品链接、封面地址。
- CSV 带 UTF-8 BOM 与单元格转义；JSON 为同字段的对象数组。
- 导出成功显示绿色提示条与完整路径；取消保存不提示。

### 3.7 分页

- 每页条数等于「每页数量」配置项。
- 页码条位于列表底部：上一页、页码、下一页；超过 7 页时以省略号折叠，始终保留首尾与当前页附近的页码。
- 显示当前区间，例如 `1–48 / 167`，以及本页已选数量。
- 翻页后列表自动滚动回顶部。
- 筛选导致结果变少时，页码自动收回到最后一页，避免空白页。
- 抓取完成后默认停在第 1 页，并默认全选第一页作品。

### 3.8 标签搜索建议

**入口**：左侧「标签」输入框。

**需求**

- 输入长度达到 2 个字符后，防抖 350ms 请求 pixiv 标签补全接口。
- 下拉展示候选标签及中文/罗马音翻译，合并「搜索词、规范标签、父标签、关联标签」并去重。
- 支持键盘操作：↑/↓ 切换、Enter 确认、Esc 关闭；点击外部自动关闭。
- 请求带序号防竞态，过期响应丢弃；加载中显示转圈。
- 接口无结果时静默处理，不影响正常输入。
- 说明：pixiv 该接口本身只返回单个最佳匹配标签，因此下拉通常只有 1–3 条。

### 3.9 作品详情与多图预览

**入口**：点击作品卡片。

**需求**

- 弹窗展示：标题、作者、作品 ID、作品页数、原图尺寸、单页尺寸、跳转 pixiv 作品页的链接。
- 通过分页接口拉取该作品的全部分页图片地址，默认按全局下载质量展示预览；头部提供「常规图 / 高清原图」切换。
- 点击任意缩略图在应用内打开全屏图片预览（不跳转浏览器）：支持滚轮/按钮缩放、拖拽平移、触控板双指缩放、旋转 90°、水平/垂直翻转、适应屏幕、左右切换与键盘（← → / + - / 0 / Esc）。
- 动图作品的预览为封面帧，并提示下载后保存为 `.zip` 帧压缩包。
- 加载中显示「正在解析图片地址…」；无图或接口失败展示对应提示。
- 底部按钮：关闭、加入下载 / 已选中（与列表选中状态联动）。
- Esc 或点击遮罩关闭；弹窗内点击不关闭。

### 3.10 下载执行

**入口**：左侧「下载选中作品（N）」。

**流程（两阶段）**

1. **解析阶段**：并发请求每个选中作品的分页接口，得到每张图的下载地址、原始尺寸与目标路径；单个作品解析失败只记录「解析失败」，不中断任务。
2. **下载阶段**：并发下载每张图片；目标文件已完整存在且满足当前质量时记为「已存在」并跳过，尺寸不满足时重新下载覆盖，日志记为「覆盖」。

**需求**

- 未选中作品、未配置 Cookie、保存目录非法时禁止开始。
- 同一时间只允许一个下载任务运行，重复开始会被拒绝。
- 下载质量按当前配置选择：`regular` 使用常规图地址，`original` 使用高清原图地址；对应字段缺失时互相回退。
- 常规图与高清原图共用同一文件名，已存在文件按像素尺寸校验（读取 PNG/GIF/JPEG 文件头，不整图解码）：
  - 选择 `original`：已有文件尺寸与作品原始尺寸不一致（典型是长边 1200 的常规图）时覆盖重下；
  - 选择 `regular`：已有任意成品都视为满足，避免把已有的原图降级覆盖成小图；
  - 尺寸未知（旧队列快照、动图 zip）或无法解析时退回「存在即跳过」。
- 动图（ugoira）作品通过 `ugoira_meta` 接口取得帧压缩包地址，按单文件下载为 `.zip`，不受下载质量影响。
- 下载使用 `.part` 临时文件，成功后原子重命名为正式文件（支持 `.jpg/.png/.gif/.zip` 等按 URL 后缀推断，缺省 `.jpg`）。
- 单文件失败自动重试；确定性 4xx 不重试；429 触发全局冷却后重试，且不计入失败。
- 中止（暂停）时立即停止取新任务，已完成的文件保留。
- 任务结束后返回汇总：阶段、计数、字节数、用时、输出目录、是否暂停。

### 3.11 进度反馈

**入口**：右侧顶部进度卡片。

**需求**

- 阶段：等待开始 / 解析分页 / 下载中 / 已暂停 / 已完成。
- 解析阶段按「已解析作品数/总作品数」计算百分比；下载阶段按「已完成图片数/总图片数」计算。
- 统计项：成功、已存在、失败、解析失败、已下载字节、用时。
- 下载进行中每秒刷新用时。
- 出现限流时显示提示徽标：`接口/图片限流冷却中 Ns（并发 X）` 或 `已自动降速：接口并发 X`。
- 未开始下载时展示引导文案。

### 3.12 队列持久化与断点续传

**入口**：右侧「未完成任务」卡片；左侧「暂停下载（可续传）」。

**任务快照**

- 位置：`userData/queue.json`。
- 内容：任务 ID、标签、保存目录、作品根目录、状态、创建/更新时间、作品快照、每张图片任务（作品 ID、URL、目标路径、相对标签、状态、字节数、错误）、作品解析失败记录、进度计数。
- 写入策略：临时文件 + 重命名原子写；更新防抖 500ms；退出前强制执行并落盘。
- 状态：解析中 / 下载中 / 已暂停 / 已完成；已完成且无失败项的任务会从队列中移除。
- 上次运行中未完成的任务，重启后一律视为「已暂停」。

**续传规则**

- 已完成（成功/已存在）且文件仍存在的图片直接跳过；文件被删除的重新排队。
- 上次失败的图片重置为待下载并重试。
- 已有任务记录的作品不重复解析分页，只解析新增作品。
- 续传时进度计数从快照恢复，不从头开始。
- 退出应用时先中止运行中的任务、以「已暂停」状态落盘，再退出。

**界面**

- 显示每个未完成任务的标签、作品数、完成比例、失败数、解析失败数、待下载数、已下载字节、耗时。
- 操作：继续 / 重试失败项、失败详情、导出清单、移除、打开目录；任务运行中时「继续/重试/移除」禁用。
- 有失败项时按钮文案变为「重试失败项 N」，无失败项时为「继续」。

### 3.12.1 失败重试中心

**入口**：右侧「未完成任务」卡片中的失败相关按钮。

**失败清单**

- 两类失败统一汇总：作品解析失败（没有分页任务）与图片下载失败（单张原图）。
- 清单项包含：类型、作品 ID、文件相对路径（或作品名）、图片地址、错误原因。
- 解析失败记录随任务快照持久化，因此在重启后仍可查看与重试。
- 图片失败直接由任务状态 `failed` 推导，不额外存一份，避免状态不一致。

**重试**

- 「重试失败项」复用队列续传逻辑：失败的图片重置为待下载，解析失败的作品重新解析分页，成功/已存在的不重复下载。
- 重试前会清空该作品旧的解析失败记录，避免同一错误重复累积。
- 重试过程与正常续传一致，进度从快照恢复，实时写入日志与进度卡片。

**失败详情**

- 按需加载（展开时才请求），按「解析 / 下载」标签区分类型。
- 显示总数与逐条错误原因，最多展示 40 条高度内滚动。

**导出清单**

- 导出为 CSV，系统保存对话框默认落到「下载」目录，文件名带时间戳。
- 列：类型、作品ID、文件/作品、图片地址、错误原因；单元格做引号转义，文件带 UTF-8 BOM，Excel 打开中文不乱码。
- 导出成功后界面出现绿色提示条，展示完整保存路径；取消保存不提示。

### 3.13 下载日志

**入口**：右侧「下载日志」标签页。

**需求**

- 实时追加每张图片的结果：完成（含文件大小）、已存在、覆盖（尺寸不符覆盖重下）、失败（含错误原因）。
- 最新记录置顶，最多保留 500 条。
- 运行中底部显示「正在继续…」。
- 无记录时显示空状态引导。

### 3.14 文件名模板

**入口**：顶栏「设置」按钮打开的设置弹窗（与保存目录同属全局设置）。

**变量**

| 变量 | 含义 |
| --- | --- |
| `{id}` | 作品 ID（必填） |
| `{page}` | 页码，从 0 开始，与 pixiv 一致 |
| `{page1}` | 页码，从 1 开始（与 `{page}` 二选一） |
| `{title}` | 作品标题 |
| `{author}` | 作者名 |
| `{userid}` | 作者 ID |
| `{tag}` | 当前标签目录名（收藏夹为「收藏夹」） |
| `{date}` | 发布日期 `YYYY-MM-DD` |
| `{ext}` | 扩展名（如 `.jpg`） |

**规则**

- 模板必须包含 `{id}` 与页码变量之一，否则多作品/多页会重名；校验不通过时输入框下方红字提示，并禁用「下载选中作品」。
- 模板不能包含路径分隔符；目录固定为 `{标签}/{作者ID}_{作者名}/`。
- 变量值中的 `\ / : * ? " < > |` 与换行制表符替换为 `_`，并去掉首尾的点、空格、下划线。
- 空变量（如无发布日期）留下的连续下划线/短横自动折叠，避免出现 `__`。
- 未写 `{ext}` 时自动追加扩展名；整体文件名超过 120 字符时截断。
- 预览区用样例数据实时渲染，`{ext}` 变量与模板编辑均即时生效；「恢复默认」回到 `{id}_p{page}_{title}`。
- 「已下载」判定按当前模板解析文件名中的作品 ID 与页码，**同时兼容默认模板**，因此改模板不会让历史文件变成未下载。
- 切换模板后，新下载按新模板命名；已完成的任务快照保留原有路径，续传不会重命名。

### 3.15 已下载判定（严格校验）

**需求**

- 依据保存目录下 `{标签}/{作者目录}/`（收藏夹来源为 `收藏夹/{作者目录}/`）中的文件名统计：默认 `{作品ID}_p{页码}_{标题}{扩展名}`，或当前配置的模板。
- 只有作品 `0 ~ pageCount-1` 的每一页都存在成品文件，才判定为「已下载」。
- `.part` 临时文件不计入。
- `pageCount` 未知（≤0）时退化为「存在任意一张成品图」。
- 选择高清原图时，还会校验作品首页文件的像素尺寸是否等于原图尺寸；长边 1200 的常规图会被判定为「未下载」（切换质量后自动重新扫描）。
- 判定时机：抓取作品列表后、下载任务结束（完成或暂停）后、切换下载质量后、开启「只看未下载」时。

### 3.16 关注列表

**入口**：作者标签来源下的「从关注列表选择画师」按钮。

**需求**

- 读取当前登录账号的关注列表（接口 `/ajax/user/{id}/following`），需要有效 Cookie。
- 弹窗内以卡片展示每位画师：头像、名称、用户 ID、简介（最多两行）。
- 分页：每页 48 位，底部显示「区间 / 共 N 位」、上一页、下一页、当前页码。
- 点击画师卡片：关闭弹窗，把该画师 ID 回填到「用户 ID」，并自动切换到作者标签来源、立即抓取其作品列表。
- 每张卡片提供「pixiv」外链按钮，跳转该画师主页，且不会触发抓取。
- 头像来自 `i.pximg.net`，通过会话级 Referer 注入正常显示；加载失败时隐藏。
- 读不到数据或 Cookie 失效时给出错误提示，不阻塞其它操作。

### 3.17 限流治理（429）

**背景**：解析与翻页都走接口，聚合请求速率超过 pixiv 对单 IP 的限制时返回 429，单纯加大每任务间隔效果有限。

**需求**

- 全局按类别限速：接口类（API）与图片 CDN 类分别限制并发与最小请求间隔，默认接口 2 并发 / 650ms，图片 6 并发 / 120ms。
- 翻页并发额外限制为最多 3 路。
- 收到 429 时：
  - 优先读取 `Retry-After`（秒数或 HTTP 日期）；
  - 对整类请求设置全局冷却，无 `Retry-After` 时按指数退避（起点约 2.5s，上限 45s）并加抖动；
  - 下调该类别并发（每次 -2，最低 1）；
  - 429 不计入失败，重试次数：接口 5 次、图片 4 次。
- 连续成功 8 次后逐级恢复并发。
- 冷却与降速状态通过事件推送到界面展示。

### 3.18 多标签组合搜索

**入口**：左栏「抓取设置」→「多标签组合」区块（附加包含标签、排除标签、组合方式）。

**需求**

- 在主标签之外可追加多个包含标签，并选择两种组合方式：
  - **同时满足（AND）**：作品标签需同时包含主标签与所有附加标签；
  - **任一满足（OR）**：作品标签包含主标签或任意一个附加标签即可。
- 「排除标签」中的任意一个出现在作品标签里，该作品被丢弃。
- 标签以芯片形式输入：回车/逗号添加，退格删除最后一个，带 pixiv 关联标签建议。
- 抓取策略（为控制请求量）：
  - AND：只用第一个包含标签调用接口，其余标签在本地按作品返回的 `tags` 过滤；
  - OR：按每个包含标签依次抓取（顺序执行，不叠加并发），合并去重后再过滤；
  - 收藏夹来源同样生效：收藏标签为空时先抓取全部收藏，再本地按标签筛选。
- 作品没有返回标签信息时保留作品，避免静默漏抓。
- 组合标签只影响抓取结果，不改变落盘目录：目录仍按主标签（收藏夹为「收藏夹」）命名。
- 对比：本地「过滤规则」中的「排除标签」是对已抓取结果的后置过滤；这里是在抓取阶段缩小结果集。

### 3.19 动图（ugoira）支持

**入口**：无需单独入口；列表、详情与下载流程自动识别动图作品。

**需求**

- 作品列表接口返回 `illustType = 2` 时视为动图，卡片与详情弹窗显示「动图」徽标。
- 详情弹窗只预览封面帧，并提示下载结果为帧压缩包。
- 解析阶段调用 `/ajax/illust/{id}/ugoira_meta` 取得 `originalSrc` / `src` 作为 zip 地址，按单个文件加入下载任务。
- 文件按当前文件名模板命名，扩展名由 URL 推断为 `.zip`；`.part` + 原子重命名等落盘规则与普通图片一致。
- 已下载判定沿用严格校验：模板解析出该作品 `p0` 文件即视为已下载。
- 任务快照、断点续传、失败重试、失败清单与日志对动图任务同样生效。
- 当前不做 MP4 / GIF 转码（环境无 ffmpeg），转码需求记录在 `SHELVED.md`。

### 3.20 本地图库浏览

**入口**：右侧「本地图库」标签页。

**需求**

- 扫描当前保存目录（结构为「标签 / 作者 / 文件」），按「标签目录 + 作品 ID」聚合为作品卡片。
- 文件名用当前模板解析作品 ID 与页码，并兼容默认模板，避免改模板后历史文件无法识别；`.part` 与隐藏文件忽略。
- 下载时写入 `userData/history.json` 索引（按文件绝对路径记录标题、作者、标签、页码、大小、是否动图），图库优先取索引中的元数据；索引缺失时回退为「作品 {id}」与作者目录中的用户名。
- 提供关键词搜索（标题/作者/作品 ID）、标签筛选、排序（最近更新、文件数、占用空间、作品 ID）与分页（每页 48 个）。
- 卡片展示封面、文件数、占用空间、标签、更新时间与动图徽标；悬停可打开该作品所在文件夹。
- 点击卡片打开应用内全屏预览（与作品详情共用预览组件），动图作品的 `.zip` 不参与预览。
- 工具栏「重新扫描」强制跳过 15s 缓存重新扫描；「打开图库」在系统文件管理器中打开保存目录。
- 本地图片通过主进程注册的 `pixivfile://` 协议加载，仅允许读取保存目录内的文件。
- 下载完成或修改保存目录后自动失效缓存，下次进入图库即为最新结果。

## 4. 非功能需求

### 4.1 性能

- 作品列表上千条时，分页切片与筛选在渲染层完成，避免一次渲染全部卡片。
- 缩略图懒加载；图片加载失败降级为占位符。
- 下载写盘流式进行，不整文件驻留内存。

### 4.2 稳定性

- 网络请求统一超时 30s；中止信号可随时取消请求与写盘。
- 配置文件、Cookie、队列文件均使用原子写或容错读取，损坏时回落默认值。
- 单个作品/单张图片的失败不影响其他任务。

### 4.3 安全

- 渲染进程通过 preload 暴露受限 API（`window.pixiv`），不开启任意 IPC。
- Cookie 仅在界面脱敏展示，存于用户数据目录，不写入日志。
- 下载目录由用户显式选择，且必须是绝对路径。

### 4.4 兼容性

- 目标平台：Windows 桌面（当前仅在此验证）。
- 网络层依赖系统/Electron 网络栈，需可访问 pixiv。

## 5. 数据与文件规范

### 5.1 目录结构

```
{保存目录}/
  ├─ {标签}/
  │    └─ {作者ID}_{作者名}/
  │         ├─ {作品ID}_p0_{标题}.jpg
  │         ├─ {作品ID}_p1_{标题}.jpg
  │         └─ {作品ID}_p0_{标题}.zip   ← 动图作品
  └─ 收藏夹/
       └─ {作者ID}_{作者名}/
            └─ ...
```

- 标签与作者名会过滤 Windows 非法字符（`\ / : * ? " < > |`、换行、制表符）并替换为 `_`。
- 名称长度上限 80 字符，空值回退为 `tag` / `artist` / `untitled`。
- 临时文件为正式文件名后追加 `.part`，完成后原子改名。

### 5.2 配置文件

| 文件 | 位置 | 说明 |
| --- | --- | --- |
| `config.json` | `userData/` | 抓取与下载参数 |
| `pixiv_cookie.txt` | `userData/` | 已保存的 Cookie |
| `queue.json` | `userData/` | 未完成下载任务的快照 |
| `history.json` | `userData/` | 已下载文件的元数据索引（供本地图库使用） |

## 7. 边界与暂不包含

当前版本不包含：

- 关注画师的批量同步（当前为单选一位画师后抓取）、排行榜等其它来源
- 失败项的手动编辑与逐条重试（当前为整批重试失败项）
- 收藏/关注等写操作（仅读取，不做点赞与关注）
- 收藏夹增量同步的定时任务（当前为手动点击同步）
- 关注列表的搜索与排序（当前按 pixiv 默认关注顺序）
- 动图转码为 MP4 / GIF（当前仅下载帧压缩包 .zip）
- 多任务并行下载（同一时刻仅允许一个任务）
- 代理设置、登录态自动获取（需手动配置 Cookie）
- 断点续传单张图片的 HTTP Range 续传（按文件粒度重下）
- 下载历史与统计报表（已提供 `history.json` 元数据索引与本地图库，暂不做统计报表）
- 图库目录的实时文件监听（当前进入标签页或手动重新扫描时读取）
- 自动更新与安装包分发配置

上述暂不包含项与其它延后需求统一记录在 [SHELVED.md](./SHELVED.md)，后续排期从该清单取用。

## 8. 验收要点

1. 配置变更后重启应用，参数保持；保存目录非法时拒绝下载并提示。
2. 未配置 Cookie 时下载按钮禁用；配置后顶部徽标与设置弹窗均显示已配置与脱敏值。
3. 抓取 100+ 作品时进度实时更新，分页失败有提示，列表去重且顺序稳定。
4. 列表分页可切换、页码正确、默认第 1 页且默认选中第一页作品；「全选本页」只影响本页。
5. 点击卡片可预览全部页面图片，Esc 关闭；弹窗内可加入下载。
6. 标签输入 2 字符后出现建议，可用键盘选择，点击外部关闭。
7. 「只看未下载」只显示缺页作品；补齐所有页后徽标变为已下载。
8. 下载中途暂停，任务出现在「未完成任务」；关闭应用再启动可「继续」，已完成图片不重复下载。
9. 下载日志实时记录成功/已存在/失败及原因。
10. 连续快速抓取触发 429 时，界面显示冷却倒计时，冷却结束后任务继续且不被计为失败。
11. 配置 Cookie 后设置弹窗显示当前登录昵称与 ID；切到「我的收藏」时可留空收藏用户 ID 直接同步。
12. 收藏夹同步默认开启「只同步未下载」，二次同步时已完成的作品不再出现在默认选中范围内。
13. 过滤规则即时生效：调整页数、分级、排除标签/关键词后列表数量与「规则过滤 N」同步变化，勾选范围随之收缩。
