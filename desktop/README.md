## 1. 快速开始

首次使用按下面五步走，即可完成一次「找作品 → 下载 → 本地查看」的完整流程。

### 第 1 步：设置保存目录

1. 点击顶栏右侧的 **设置**（齿轮图标）。
2. 在「保存目录」中选择一个**绝对路径**（如 `D:\pixiv_downloads`）。
3. 关闭设置弹窗，配置自动保存。

> 保存目录不合法时无法开始下载，界面会直接提示。

### 第 2 步：登录 pixiv

1. 仍打开 **设置**，找到「Cookie」区域。
2. 点击 **登录 pixiv**，在弹出的独立窗口中输入 pixiv 账号密码。
3. 登录成功后窗口自动关闭，设置里显示「已配置」与脱敏 Cookie，并显示当前登录昵称与 ID。

无法在窗口内登录时，可用「手动粘贴」填入 `PHPSESSID=...` 或完整 Cookie 字符串。

> 未配置 Cookie 时「下载选中作品」按钮不可用——未登录状态下 R-18 作品会被 pixiv 过滤。

### 第 3 步：抓取作品

1. 进入顶栏 **工作台**。
2. 在左栏填写 **用户 ID**（作者 ID）；按需填写标签，可选栏目「全部 / 插画 / 漫画 / 收藏」。
3. 点击 **抓取作品列表**，右侧「作品列表」会边抓边显示进度。

### 第 4 步：挑选作品

- 点击卡片切换选中状态；「全选本页」可一次选中当前页。
- 用「只看未下载」「排序」「过滤规则」缩小范围。
- 点卡片上的 **详情** 可查看大图与页数。

### 第 5 步：加入下载

1. 点击左栏 **下载选中作品（N）**（队列里已有任务时按钮变为「添加到任务队列」）。
2. 右侧切到 **下载任务** 标签页，查看每个任务的进度。
3. 完成后到 **图库** 查看与预览本地文件。

## 2. 界面总览

### 顶栏

| 区域 | 内容                                                                                                                                          |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| 左侧 | 主栏目切换：**推荐 / 排行榜 / 插画 / 漫画 / 小说 / 用户**，以及 **工作台 / 图库 / 稍后看** 图标入口                                           |
| 中部 | 全局搜索框：回车提交；展开时无关键词显示「搜索历史 + 热门标签」，有关键词显示 pixiv 联想（≥2 字符）；切栏目会记住上次搜索词                   |
| 右侧 | 账号菜单（关注列表 / 收藏 / 浏览记录 / 设置）、**过滤规则**（带生效条数角标）、Cookie 状态徽标、打开保存目录、**设置** 齿轮、产品引导回放 `?` |

### 工作台

- **左栏（抓取面板）**：作品来源与抓取参数、多标签组合、下载质量、抓取 / 关注列表 / 下载按钮。暂停与取消不在这里，交给任务卡片。
- **右栏**：错误提示条 + 三个标签页：
  - **作品列表**：工具栏（过滤、排序、导出、只看未下载、全选本页、分页）、作品卡片网格。
  - **下载任务**：总进度卡片 + 未完成任务卡片。
  - **下载日志**：逐张图片的实时结果，最多 500 条。

### 其他页面

- **图库**：作者列表 → 作者页（插画 / 漫画 / 小说三个栏目）。
- **插画 / 漫画**：pixiv 作品搜索页，支持关键词、排序、筛选 chip 与分页；点缩略图在应用内预览。
- **小说**：小说搜索、系列目录、阅读器。
- **用户**：用户搜索 → 用户主页。
- **收藏 / 浏览记录 / 稍后看**：账号菜单与顶栏入口打开。
- **排行榜 / 推荐**：独立页面，状态记在地址栏，刷新后停留在原处。

> 推荐、排行榜、插画、漫画、小说、用户这六个列表页会被缓存：离开再回来不重新请求，并恢复原滚动位置；需要最新数据时点页面上的「刷新」。

## 3. 账号与登录

### 3.1 Cookie（读取数据必需）

**推荐：应用内登录**

1. 设置 → Cookie → **登录 pixiv**。
2. 在独立窗口完成登录；成功后自动保存会话 Cookie（只取 `PHPSESSID`）。
3. 已登录状态下再次打开无需重输密码；同一时间只允许一个登录窗口。

**兜底：手动粘贴**

- 支持只填 `PHPSESSID` 的值，程序自动补全为 `PHPSESSID=...`；
- 多行输入会合并为 `key=value; key=value`。

**状态与来源**

- 顶部徽标与设置里都会显示 Cookie 来源（环境变量 / 本地文件 / 未配置）与脱敏值。
- 登录成功后会调用用户信息接口识别当前账号（昵称 + ID），用于「收藏」栏目的默认用户与关注列表。
- 登录中直接关窗视为取消，原有 Cookie 保持不变并给出提示。

> 软件**不会**读取 Chrome / Edge 的系统 Cookie，请在应用内登录或手动粘贴。

### 3.2 App API 凭据（收藏、关注、追更等写操作）

pixiv 的写操作走另一套认证，需要在设置中连接：

1. 设置 → **App API 凭据（写操作）** → 点 **通过 pixiv 登录获取**（推荐）。
2. 授权窗口共用 Cookie 登录分区，已登录过会直接跳回并自动完成。
3. 状态变为「已连接」，显示 pixiv 用户 ID 与 refresh_token 后四位。

也可手动填写 `client_id` / `client_secret`（留空使用内置默认）与 `refresh_token`，点 **保存并验证**：

- 校验成功才落盘；失败时原凭据不变并显示原因。
- `refresh_token` 无效 → 提示重新导入；`client_id` / `client_secret` 不正确 → 提示检查凭据。

**影响范围**

- 未连接时，作品收藏、画师关注、小说收藏、系列追更按钮不显示，不会发请求。
- Cookie 失效与 App API 失效互不影响。
- 清除凭据需二次确认，只影响写操作，不影响浏览与下载。

## 4. 抓取作品

### 4.1 选择来源：四个栏目

作品列表顶部栏目条「全部 / 插画 / 漫画 / 收藏」，与左栏参数共用同一个 **用户 ID**：

| 栏目 | 含义                | 需要填写                             |
| ---- | ------------------- | ------------------------------------ |
| 全部 | 该作者的插画 + 漫画 | 用户 ID（必填）                      |
| 插画 | 该作者的插画        | 用户 ID（必填）                      |
| 漫画 | 该作者的漫画        | 用户 ID（必填）                      |
| 收藏 | 该用户的收藏夹      | 用户 ID 可留空（留空用当前登录账号） |

- 栏目属于配置项，重启后保持；切换栏目时参数齐全会自动重抓一轮。
- 收藏栏目额外多出「收藏类型（公开 / 私密）」；**私密收藏只有本人可见**，填他人 ID 时私密选项禁用。
- 「标签」在作者栏目是作品标签，在收藏栏目是收藏夹标签（接口级过滤，留空为全部）；切换栏目会各自记住上次输入。
- 抓取进行中栏目条与「抓取作品列表」按钮禁用，避免重复提交。

### 4.2 抓取参数

| 字段           | 说明                               | 默认        |
| -------------- | ---------------------------------- | ----------- |
| 用户 ID        | 作者 ID（收藏栏为收藏夹所属账号）  | `114638697` |
| 标签           | 主标签；留空表示该作者全部作品     | `R-18`      |
| 起始偏移       | 从第几个作品开始抓取               | 0           |
| 每页数量       | 单次请求条数，同时作为列表翻页步长 | 48          |
| 并发数         | 同时解析 / 下载的任务数            | 8           |
| 请求间隔（秒） | 每个任务开始前的额外等待           | 0.2         |

- 用户 ID 为空时「抓取作品列表」禁用，标签前显示红色 `*`。
- 抓取结果按作品 ID 去重，保持接口顺序；分页失败不阻断整体，结束后提示「N 个分页抓取失败」。
- 抓取会重置列表、清空预览、回到第 1 页，并重新扫描本地已下载状态；默认选中第一页作品。

### 4.3 多标签组合

左栏「抓取设置 → 多标签组合」：

- **附加包含标签**：在主子标签之外追加多个标签，回车 / 逗号添加，退格删除最后一个。
- **组合方式**：
  - 同时满足（AND）——作品需同时包含主标签与全部附加标签；
  - 任一满足（OR）——包含主标签或任意附加标签即可。
- **排除标签**：命中任意一个即剔除该作品。
- 组合标签只影响抓取结果，不改变落盘目录（目录始终按作者）。
- 与「过滤规则 → 排除标签」的区别：这里在抓取阶段缩小结果；过滤规则是对已抓取结果的本地后置过滤。

### 4.4 从已关注选择画师

1. 点击头像下拉框中的 **已关注**（需要有效 Cookie）。
2. 在画师列表中浏览当前账号关注的画师，点击头像后可进入详情页浏览画师的作品（通过搜索用户也可进入详情页）。
3. 详情页支持三种操作：
   - **关注/取关** → 切换关注状态；
   - **转到下载页面** → 回填用户 ID 并立即抓取该画师的所有作品，需要手动确认下载；
   - **pixiv** → 在浏览器打开该画师主页（不触发抓取）。

### 4.5 标签筛选弹窗

- 作品列表工具栏的 **标签** 按钮打开作者标签云：按使用次数排序，显示译名与作品数，支持关键字过滤，**单选**。
- 选中后关闭弹窗、回到第 1 页并按该标签重新抓取；「全部作品」或工具栏 `×` 清除标签。
- 计数行右侧 **刷新** 可忽略缓存强制重拉；刷新期间保留当前列表，失败只在顶部提示。
- 标签列表按「作者 + 栏目」缓存 10 分钟。
- 收藏栏目不显示该入口（收藏夹标签只能手填）。

### 4.6 标签输入建议

- 在标签输入框输入 2 个字符后，350ms 防抖出现建议（含中文 / 罗马音）。
- `↑` / `↓` 切换、`Enter` 确认、`Esc` 关闭；点击外部自动关闭。
- 通常只有 1–3 条候选（pixiv 接口本身只返回最佳匹配）。

## 5. 浏览与挑选作品

### 卡片信息

- 缩略图（加载失败时显示占位图标）。
- 缩略图左上角勾选框；图上角标显示名次、R-18、AI、动图等标记。
- 左下角「已下载」徽标。
- 标题（最多两行）、作者名、多图作品的「N 页」。
- 信息区右侧 **详情** 按钮。

### 交互

- 点击卡片任意区域切换选中；点 **详情** 打开弹窗（不触发选中）。
- 键盘 `Enter` / `Space` 在卡片上等同点击（切换选中）。
- 顶部统计：筛选后作品数、接口总数、规则过滤数、已下载数、已选数。
- **只看未下载**：仅显示本地判定未完整下载的作品，开启时回到第 1 页。
- **排序**：默认顺序 / 页数最多 / 页数最少 / 最新发布 / 最早发布；切换后回到第 1 页。
- **全选本页 / 取消全选**：只作用于当前页。
- **导出**：把当前筛选后的**全部**结果导出为 CSV 或 JSON（不限于当前页）。

### 导出清单字段

作品 ID、标题、作者 ID、作者、页数、宽、高、分级、AI、发布时间、标签、已下载、作品链接、封面地址。

- CSV 带 UTF-8 BOM，Excel 打开中文不乱码；取消保存不提示，成功显示完整路径。

### 分页

- 每页条数等于「每页数量」。
- 页码条：上一页 / 页码 / 下一页；超过 7 页折叠，始终保留首尾与当前页附近。
- 显示当前区间（如 `1–48 / 167`）与本页已选数；翻页后自动回到顶部。
- 筛选导致结果变少时页码自动收回到最后一页。

### 作品详情与图片预览

- 详情弹窗展示标题、作者、作品 ID、页数、原图尺寸、单页尺寸与 pixiv 链接。
- 默认按全局下载质量展示分页图，可切换「常规图 / 高清原图」。
- 点击缩略图打开应用内全屏预览：滚轮 / 按钮缩放、拖拽平移、双指缩放、旋转 90°、水平 / 垂直翻转、适应屏幕、左右切换。
- 动图作品只预览封面帧，并提示下载后按设置中的「动图格式」保存。
- 底部按钮：关闭、加入下载 / 已选中（与列表选中状态联动）；`Esc` 或点遮罩关闭。

### 已下载判定

- 按保存目录中 `{作者ID}_{作者名}/illustration|manga/` 的文件名统计，默认模板 `{作品ID}_p{页码}_{标题}{扩展名}`，也兼容当前自定义模板。
- 只有作品的每一页 `0 ~ pageCount-1` 都存在成品文件，才算「已下载」；`.part` 临时文件不计。
- 选择高清原图时，还会校验首页像素尺寸；长边 1200 的常规图会被判为未下载。
- 判定时机：抓取后、下载结束（完成或暂停）后、切换下载质量后、开启「只看未下载」时。

## 6. 过滤规则与屏蔽

**入口**：顶栏 **过滤规则** 图标（角标显示生效条数）；工作台作品工具栏也有入口，并显示「规则过滤 N」。

### 6.1 规则项

| 规则         | 说明                                 | 默认 |
| ------------ | ------------------------------------ | ---- |
| 最少页数     | 总页数下限，0 不限                   | 0    |
| 最多页数     | 总页数上限，0 不限                   | 0    |
| 最小宽度     | 原图宽度下限，0 不限                 | 0    |
| 最小高度     | 原图高度下限，0 不限                 | 0    |
| 内容分级     | 全部 / 仅 R-18 / 排除 R-18           | 全部 |
| 排除 AI 作品 | 按接口 AI 标记过滤                   | 关闭 |
| 排除关键词   | 匹配标题与作者名，不区分大小写       | 空   |
| 排除标签     | 匹配作品标签，并兜底匹配标题与作者名 | 空   |

- 规则在本地实时生效：改任何一项，所有页面列表立即重算，不重新请求接口。
- 多条规则之间是「与」关系，任意一条不满足即排除。
- 生效范围：插画 / 漫画 / 小说搜索、收藏、用户主页、排行榜、推荐、下载工作台、用户搜索、关注列表、推荐画师。
- 不生效：浏览记录、稍后看、本地图库（本地既有文件不受显示规则影响）。
- 推荐页例外：作品接口不提供分级维度，「内容分级」不参与判定，过滤弹窗中该项置灰。
- 一页结果被全部挡掉时，网格显示「本页 N 个结果已被过滤规则隐藏」并提供 **调整规则**。
- 配置随 `config.json` 持久化；「清空」恢复默认，关闭弹窗即保存。

### 6.2 全局屏蔽（标签 / 用户）

- 入口：过滤弹窗内的「屏蔽标签」「屏蔽用户」输入框，以及底部 **管理屏蔽名单**。
- 屏蔽是全局的：搜索、用户主页、收藏、推荐、排行榜、下载全部生效，改完已加载列表立即重算。
- 屏蔽标签按整标签不区分大小写匹配；屏蔽用户支持「用户 ID 精确」或「作者名包含」。
- **管理屏蔽名单**：分「屏蔽的用户 / 屏蔽的标签」列出词条与匹配方式，逐条取消屏蔽，整组清空需二次确认；纯数字用户 ID 可直接在 pixiv 打开主页。
- 取消屏蔽也可在卡片右键菜单中完成（作者已被屏蔽时，菜单项会变为「取消屏蔽该作者」）。
- 屏蔽只在本地生效，不改变 pixiv 账号状态；取消后需刷新 / 重新抓取列表才会重新出现。
- 主进程与渲染层都会过滤，保证「界面上看到的」与「能下载的」一致。

## 7. 下载设置

### 7.1 下载质量

- **常规图**（约 1200px，默认）/ **高清原图**（作品原始尺寸）。
- 可在左栏下载按钮上方与设置弹窗中切换，两处共用同一份配置。
- 任务快照记录创建时的质量，断点续传沿用。

### 7.2 保存目录

- 必须是绝对路径；支持「选择目录」系统对话框与「打开目录」。
- 目录结构固定为两级：作者 → 内容类型，抓取条件不参与目录命名：

```text
{保存目录}/
  └─ {作者ID}_{作者名}/
       ├─ illustration/   插画与动图
       ├─ manga/          漫画
       └─ novel/          小说
```

### 7.3 文件名模板

设置 →「文件名模板」，支持以下变量：

| 变量        | 含义                                  |
| ----------- | ------------------------------------- |
| `{id}`      | 作品 ID（必填）                       |
| `{page}`    | 页码，从 0 开始                       |
| `{page1}`   | 页码，从 1 开始（与 `{page}` 二选一） |
| `{title}`   | 作品标题                              |
| `{author}`  | 作者名                                |
| `{userid}`  | 作者 ID                               |
| `{tag}`     | 当前任务的标签（收藏栏为「收藏夹」）  |
| `{date}`    | 发布日期 `YYYY-MM-DD`                 |
| `{quality}` | `regular` 或 `original`               |
| `{ext}`     | 扩展名（如 `.jpg`）                   |

规则：

- 必须包含 `{id}` 与页码变量之一，否则多作品 / 多页会重名；校验不通过时红字提示并禁用下载按钮。
- 模板不能包含路径分隔符；非法字符会被替换为 `_`。
- 未写 `{ext}` 时自动追加扩展名；文件名超过 120 字符会截断。
- 预览区用样例数据实时渲染；「恢复默认」回到 `{id}_p{page}_{title}`。
- 「已下载」判定兼容默认模板，改模板不会让历史文件变成未下载。
- 模板含 `{quality}` 时，常规图与原图各自落盘、互不覆盖。

### 7.4 动图格式

设置 →「动图格式」：

- **MP4 视频**（默认）/ **GIF 动图** / **保留压缩包（.zip）**。
- 缺少 ffmpeg 时自动退回 zip，不中断整批下载。
- 转码失败只影响该作品并记入失败清单。
- 动图任务沿用创建时的格式，断点续传与失败重试同样适用。

### 7.5 请求限流

设置 →「请求限流」：

| 参数         | 范围                  | 默认  |
| ------------ | --------------------- | ----- |
| 接口并发     | 1–8                   | 2     |
| 接口最小间隔 | 100–2000ms（步进 50） | 650ms |
| 图片并发     | 1–16                  | 6     |
| 图片最小间隔 | 50–1000ms（步进 10）  | 120ms |
| 并行任务数   | 1–4                   | 2     |

- 修改后关闭设置即落盘并立即生效，无需重启。
- 遇到 429 时自动全局冷却、临时降并发，冷却结束后逐步恢复到设定上限。
- 下载任务面板底部的「当前并行任务数 N」可点击直接打开设置。

## 8. 下载与队列管理

### 8.1 开始下载

1. 选中作品（或从右键菜单单独加入）。
2. 点左栏 **下载选中作品（N）**；队列非空时文案为 **添加到任务队列**，额度满也可继续添加（排队等待）。
3. 未选中作品、未配置 Cookie、保存目录非法时不会开始。

### 8.2 下载流程

每张图片分两个阶段：

1. **解析阶段**：请求作品分页接口，得到每张图地址、尺寸与目标路径；单作品解析失败只记「解析失败」，不中断整批。
2. **下载阶段**：并发下载；目标文件已完整存在时记为「已存在」并跳过；尺寸不满足当前质量时覆盖重下，日志记「覆盖」。

- 使用 `.part` 临时文件，成功后原子重命名。
- 单文件失败自动重试；确定性 4xx 不重试；429 冷却后重试且不计入失败。

### 8.3 多任务并行

- 同时运行的任务数由「并行任务数」控制（1–4）；1 为串行。
- 重复任务按作者拦截：作品全部来自同一作者时，队列里已有该作者任务会提示已存在。
- 每个任务的进度与日志独立，互不覆盖。
- 任务列表顺序固定为入队先后，进度刷新不会让卡片互换位置。

### 8.4 任务状态

| 状态            | 含义                             | 可做什么                      |
| --------------- | -------------------------------- | ----------------------------- |
| 排队中          | 等待并行额度                     | 可暂停（直接转为未完成）      |
| 解析中 / 下载中 | 正在运行                         | 暂停 / 取消（只作用于该任务） |
| 未完成（暂停）  | 用户暂停或软件退出               | 继续                          |
| 已取消          | 用户取消，已下载文件保留         | 重新开始                      |
| 失败            | 跑完但有失败项，或启动前校验失败 | 重试 / 重试失败项 N           |
| 已完成          | 无失败项                         | 自动从队列移除                |

- 三种结束态（未完成 / 已取消 / 失败）在界面上明确区分，不会混淆。
- 重启后：上次未完成的、仍排队的，一律显示「未完成」；已取消与失败原样保留。

### 8.5 进度信息

- 总进度卡片：一条汇总进度条与百分比，显示任务数、已下载字节与最长用时。
- 每个任务独立显示：成功、已存在、失败、解析失败、已下载字节、用时，以及自己的进度条。
- 出现限流时显示：`接口/图片限流冷却中 Ns（并发 X）` 或 `已自动降速：接口并发 X`。
- 任务默认折叠，只显示作者、状态与进度条；点卡片或箭头展开查看六项统计、失败详情、导出、移除、打开目录。
- 作者标识：单作者为「用户 ID-画师名」，多作者为「N 位作者」。

### 8.6 断点续传

- 已完成（成功 / 已存在）且文件仍存在的图片直接跳过；文件被删除的重新排队。
- 上次失败的图片重置为待下载并重试。
- 已有记录的作品不重复解析分页，只解析新增作品。
- 进度从快照恢复，不从头开始。
- 退出应用时先中止运行中的任务并以「已暂停」落盘。

### 8.7 自动重试与熔断

- 每个文件在传输层之外还有 2 次「整体重来」机会（共 3 次），间隔 2s / 5s；429 优先使用服务端冷却时间。
- 值得重试：限流（429 / 408）、网络（超时、连接中断、代理不可用）、服务端（5xx）。
- 一次即放弃：401、403、404 / 410（重试只会放大限流）。
- 连续 8 项系统性失败后自动中止剩余任务，任务标记「失败」，原因写「连续 N 项失败，已中止剩余任务」。
- 收藏夹里作品被删除（404）属于正常数据老化，不会触发熔断。
- 熔断后剩余文件保持「待下载」，修好 Cookie / 代理后点「重试」继续。

## 9. 失败重试与日志

### 9.1 失败清单

- 入口：下载任务卡片中的失败相关按钮。
- 两类失败统一汇总：**作品解析失败**（没有分页任务）与**图片下载失败**（单张原图）。
- 清单项：类型、作品 ID、文件相对路径（或作品名）、图片地址、错误原因。
- 失败详情按需加载（展开时才请求），按「解析 / 下载」标签区分；最多展示 40 条，高度内滚动。

### 9.2 重试

- **重试失败项 N**：复用续传逻辑，失败项重置为待下载，已成功 / 已存在的不重复下载。
- **逐条重试**：只重置该条失败项，其余保持原状态。
- 确定性失败（404 作品已删除、403 没有权限）会标注「重试也不会成功」，仍允许手动点一次，但自动重试跳过。
- 重试与正常下载同样占用并行额度；任务自身运行中时其重试按钮禁用。
- 重试成功的条目从清单消失；仍有残留失败时任务不会被误判为完成而移除。

### 9.3 导出失败清单

- 导出 CSV，默认落到系统「下载」目录，文件名带时间戳。
- 列：类型、作品 ID、文件 / 作品、图片地址、错误原因；带 UTF-8 BOM，Excel 中文不乱码。
- 成功显示完整路径；取消保存不提示。

### 9.4 下载日志

- 入口：右侧「下载日志」标签页。
- 实时追加每张图片的结果：完成（含文件大小）、已存在、覆盖、失败（含原因）。
- 最新记录置顶，最多保留 500 条；运行中底部显示「正在继续…」。

## 10. 本地图库

**入口**：顶栏 **图库** 图标。

### 10.1 作者列表

- 按作者目录聚合（`{作者ID}_{作者名}`），显示封面、作者名（含 ID）、插画 / 漫画 / 小说三类件数、文件数与占用空间。
- 点击作者进入作者页；工具栏「全部作者」返回列表。

### 10.2 作者页

- 栏目条「插画 / 漫画 / 小说」，各自带件数；进入作者时默认落在第一个有内容的栏目（插画 → 漫画 → 小说）。
- 工具栏：返回、搜索、排序（插画 / 漫画）、全文检索（小说）、重新扫描、打开作者目录。
- **插画 / 漫画**：
  - 卡片显示封面、标题、`#作品ID`、文件数、占用空间、类型、更新时间、动图徽标；悬停可打开所在文件夹。
  - 搜索只匹配标题与作品 ID。
  - 排序：最近更新、文件数、占用空间、作品 ID。
  - 虚拟滚动：上千作品只渲染可视区域。
  - 点击卡片打开应用内全屏预览（动图成品不参与图片预览）。
  - 批量操作：勾选框单选、`Shift` 连选；批量打开目录（同一目录只开一次）、批量删除（两步确认）。
  - 切换作者或栏目会清空选中项；删除后自动清理空目录并同步清理历史索引。
- **小说**：见第 11 章。

### 10.3 自动刷新

- 主进程递归监听保存目录，外部新增 / 删除 / 重命名后自动静默刷新，无需手动「重新扫描」。
- 刷新只更新数据，不重置当前作者、栏目与搜索词。
- 工具栏 **重新扫描** 可强制跳过 15 秒缓存。

### 10.4 目录兼容

- 只认 `{作者ID}_{作者名}/{illustration|manga|novel}` 结构。
- 旧版遗留的 `{标签}/{作者}/` 与 `小说/{作者}/` 不会被扫描，需要手动移动后重新扫描。

## 11. 小说

### 11.1 在线搜索

**入口**：顶栏 **小说**。

- 支持标签精确 / 标签包含 / 标题简介三种匹配。
- 排序：最新 / 最早 / 综合人气 / 男性向 / 女性向；分级：全部（含 R-18）/ 仅全年龄；最多翻到第 10 页。
- 结果卡片：封面、标题、作者、系列、标签、字数、预计阅读时间、收藏数、R-18 / AI 标记。
- 右侧相关标签，点击即换词；点卡片进入阅读器，系列角标进入系列目录。

### 11.2 系列目录

- 显示完结状态、话数、总字数、总阅读时长、简介与标签。
- 提供「开始 / 继续阅读」与「保存整部」。

### 11.3 阅读器

- 正文按 `[newpage]` 分页；支持注音、章节标题、插图。
- 阅读设置：字号 14–26、行高 1.4–2.6、正文宽度窄 / 标准 / 宽、亮色 / 护眼 / 深色主题。
- 阅读进度按小说 ID 记忆并恢复滚动位置；系列内可上一话 / 下一话，可打开目录侧栏。
- 系列最近阅读位置单独记录，目录中标记已读章节。
- 收藏按钮（需 App API）：公开 / 私密切换，已收藏时可改可见性。
- 系列页「追更 / 已追更」（需 App API）。

### 11.4 导出小说

- 单篇或整部系列保存为 UTF-8（带 BOM）TXT：
  - 路径：`{保存目录}/{作者ID}_{作者名}/novel/`
  - 整部系列逐话拉正文合并为一个文件，保存时显示进度。
- 同时写一份 `{文件名}.txt.meta.json` 元数据，供图库展示。

### 11.5 本地小说与全文检索

- 入口：图库 → 作者页 → 「小说」栏目。
- 只识别 `.txt`（单文件上限 40MB），按修改时间倒序；卡片显示封面、标题、作者、单篇 / 系列、字数、话数、修改日期。
- 点击进入应用内阅读器；卡片上可打开所在目录。
- **全文检索**：
  - 工具栏「全文检索」按钮切换后，关键词在主进程遍历全库 TXT 正文并返回命中片段；
  - 每部最多 3 段上下文，命中超过 80 部即停止；输入停顿 350ms 后检索；
  - 关闭时关键词只过滤当前作者的小说标题。
- 本地阅读器与在线阅读器共用阅读设置与进度记忆（进度以文件路径为键）。

## 12. 其他浏览页面

### 12.1 插画 / 漫画搜索页

- 入口：顶栏主栏目 **插画** 或 **漫画**。两者共用一套界面，只是请求范围与部分筛选文案不同。
- 在顶栏搜索框或页面内输入关键词，回车即搜索；关键词为空时不发请求。
- **排序**：最新发布 / 最早发布；**筛选 chip**（按当前结果动态出现）可切换：
  - 热门度排序（如「受男性欢迎」）——会员专属项不展示；
  - 内容分级（全部 / 全年龄 / R-18）；
  - 标签精确匹配；
  - 收藏数下限；
  - 「包含漫画」等栏目相关选项。
- 已应用的 chip 会从候选行消失，点已激活的 chip 可还原为默认值；所有筛选与页码都记在地址栏，便于分享与回退。
- 点作品缩略图在应用内全屏预览；卡片右上角图标跳转 pixiv 详情。
- 分页条与工作台一致；过滤规则、屏蔽名单在此页同样生效。
- 页面被缓存，返回时保留列表与滚动位置；需要刷新数据时点页面「刷新」。

### 12.2 用户搜索与用户主页

- 顶栏 **用户**：搜索用户，结果可点击进入主页。
- 用户主页 `/user/{userId}`：
  - 四栏目「插画 / 漫画 / 小说 / 收藏」，计数来自作者主页；作品按最新在前，每页 48 条。
  - 栏目与页码写进地址栏，用替换方式更新，本页在历史里只占一条；「返回」回到进入前的页面。
  - **转到下载页面**：跳到工作台，回填该作者 ID、清空标签并抓取第一页；若已有抓取任务在跑，只回填参数不重复抓取。
  - 关注按钮（需 App API）：关注 / 取关，自己的主页不显示。

### 12.3 收藏浏览页

- 入口：顶栏 / 账号菜单 **收藏**。
- 按用户 ID 读取收藏；用户 ID 留空会提示，点 **我的收藏** 填入当前登录账号。
- 公开 / 私密切换；指定他人 ID 时选私密会直接提示且不发请求。
- 标签筛选可一键清除；点卡片打开详情（自动写入浏览记录）。
- 页面状态（用户 ID / 公开私密 / 标签 / 页码）记在地址栏。

### 12.4 浏览记录

- 入口：账号菜单 **浏览记录**。
- 打开作品详情即记录：作品 ID、标题、作者、缩略图、页数、分级、类型、浏览时间；同一作品只保留最近一条并置顶。
- 最多 1000 条；列表按时间倒序，支持关键词过滤与分页。
- **清空记录** 需二次确认。

### 12.5 稍后看

- 入口：顶栏图标；作品详情页脚 **稍后看** 按钮。
- 纯本地列表，与 pixiv 收藏无关：收藏是服务端长期归档，稍后看是本地临时书签。
- 重复加入同一作品只更新时间并置顶；上限 2000 条。
- 详情弹窗中点击可加入，按钮变为「已加入稍后看」，再点移出；不需要 App API。
- 列表页按加入时间倒序，支持关键词过滤与分页（每页 24），卡片右上角悬停显示 **移出**，支持二次确认清空。

### 12.6 排行榜

- 入口：顶栏 **排行榜**。
- 7 种榜单：今日 / 本周 / 本月 / 新人 / 原创 / 男性向 / 女性向；插画与漫画各自独立。
- 日期默认最新一期；可选历史日期回看，点 **最新一期** 清除日期。
- 每页 50 件，最多 10 页；显示榜单日期、下一期日期与总数。
- 卡片左上角显示名次 `#N`；全局屏蔽在此页同样生效。

### 12.7 推荐

- 入口：顶栏 **推荐**。
- **作品推荐**：已连接 App API 时走 App API 推荐并支持续拉；未连接时回落网页发现内容（10 件，内容有限）。
- **画师推荐**：仅 App API 提供；未连接时显示连接引导。
- 触底自动续拉（无「加载更多」按钮），按作品 / 用户 ID 去重；**刷新** 重置为第一批。
- 全局屏蔽作用于推荐作品与画师。

### 12.8 系列聚合浏览

- 入口：作品详情弹窗标题下的「所属系列《…》第 N 话」。
- 已连接 App API 时按 `next_url` 翻页取完整目录，显示标题、简介、作者、封面、话数、完结状态。
- 未连接或请求失败时，用当前作品的系列信息兜底，只显示当前这一话，并提示连接凭据后可浏览完整目录。
- 已连接时显示「追更 / 已追更」（漫画系列）。
- 点任意一话打开应用内作品预览。

### 12.9 写操作

以下操作需要 App API 凭据：

- **作品收藏**：详情弹窗底部「收藏 / 已收藏」，支持公开 / 私密；已收藏时切换可见性会重新提交。
- **画师关注**：用户主页「关注 / 已关注」，可再次点击取关。
- **小说收藏**：阅读页顶栏，带公开 / 私密切换。
- **小说 / 漫画系列追更**：系列页「追更 / 已追更」。

操作进行中按钮禁用并转圈；失败时显示错误文案，不改变已显示状态。凭据失效时提示「App API 凭据已失效，请在设置中重新连接」。

## 13. 卡片右键菜单

作品卡与用户卡都支持右键唤出菜单，卡片上无需常驻图标。

### 作品卡

应用内预览、在 pixiv 打开、查看作者主页、加入下载队列、加入 / 移出稍后看、复制作品链接、复制作品 ID、屏蔽该作者（已屏蔽时变为「取消屏蔽该作者」）。

### 用户卡

### 其他

- 浏览记录 / 稍后看卡片同样支持右键菜单（可加入下载或复制链接）。
- 菜单随视口自动收敛，右下角右击也不会跑出屏幕；`↑` / `↓` 在菜单项间移动，`Esc` 关闭。
- 点击别处、滚动、窗口失焦、缩放都会关闭菜单。
- 操作结果以窗口底部轻提示反馈（成功 2.2 秒、失败 4.2 秒自动消失）。
- 屏蔽写入本地配置，只影响之后的请求；当前列表需重新抓取或翻页才会消失。

## 15. 托盘常驻与后台下载

- 默认关闭窗口 / 最小化时收进托盘，下载任务继续运行。
- 托盘菜单：版本号（只读）、显示 / 隐藏主窗口、任务进度汇总与 **全部暂停 / 全部继续**、打开下载目录、退出。
- tooltip 跟随队列：`下载中 N 个任务 · P%`、`N 个任务已暂停` 或仅应用名。
- **全部暂停** 把运行中任务转为未完成（可继续），排队中的直接标记暂停；**全部继续** 把暂停 / 失败 / 取消的任务重新入队。
- 第一次收进托盘会弹一次托盘气泡说明「仍在后台运行」，本次运行内不重复。
- 单实例：再次双击桌面图标只会把已有窗口叫出来，不会启动第二份进程。
- **下载完成提醒**：仅在窗口不在前台（隐藏 / 最小化 / 失焦）时弹出；有失败项时显示数量。
- 设置 →「托盘与后台」四项即时生效；关掉「显示托盘图标」后，关窗口会直接退出。

## 16. 外观、语言与自动更新

### 主题

- 浅色 / 深色 / 跟随系统；默认深色。
- 切换立即生效，无需重启；「跟随系统」会随操作系统深浅色变化。
- 冷启动做了防闪烁处理。

### 界面语言

- 简体中文（默认）/ English / 日本語。
- 切换后整页重载一次，仍停在当前路由；`config.json` 与首屏语言镜像同步更新。
- pixiv 接口标题与标签译文随界面语言变化；重新请求后才会换译文。
- `<html lang>` 同步更新。

### 自动更新

- 仅打包安装版生效，开发环境不检查。
- 启动后 8 秒自动检查；设置中可手动「检查更新」并显示当前版本。
- 发现新版本后台自动下载，不打扰；下载完成后弹窗「新版本 vX 已就绪」，可选 **立即重启并安装** 或 **取消更新**。
- 点「取消更新」不会在退出时偷偷安装；下次启动会复用已下载的安装包（约 1 秒内弹窗）。
- 检查失败、无更新等状态在设置中显示，不弹窗打扰。

### 产品引导

- 首次启动自动出现 7 步气泡引导，覆盖搜索、账号菜单、过滤规则、右键卡片、采集来源、作品工具栏、三个标签页。
- 完成、跳过或 `Esc` 退出后不再自动出现。
- 顶栏 `?` 图标可随时重播。

## 17. 网络代理

- 入口：设置 →「网络代理」。单套配置统一作用于接口请求、图片下载与 pixiv 登录窗口。
- 支持协议：HTTP、HTTPS、SOCKS4、SOCKS5；主机与端口必填。
- 本地 v2rayN / Clash 的混合端口属于普通 HTTP 代理，应选 **HTTP**；选 HTTPS 指与代理本身建立 TLS 连接，选错会报代理连接失败。
- 支持「不走代理的地址」（逗号分隔，如 `localhost, 127.0.0.1, <local>`）。
- HTTP / HTTPS 代理支持账号密码；SOCKS4 / SOCKS5 不支持认证，界面会禁用账号密码输入。
- 代理密码加密保存，不出现在 `config.json`。
- 修改后立即应用并断开旧连接，无需重启；启动时在建窗口前应用。
- **测试连接**：使用与真实请求相同的请求头通过当前代理访问 pixiv；能收到 HTTP 响应即视为链路正常，4xx / 5xx 会单独提示「代理已连通但 pixiv 拒绝请求」，只有网络层失败才判为连接失败。
- 面板显示 Chromium 解析出的实际路由（如 `PROXY 127.0.0.1:10808`、`DIRECT`），可确认代理是否真正生效。

## 19. 数据与文件位置

### 19.1 下载目录

见 [7.2 保存目录](#72-保存目录)。作者名会过滤 Windows 非法字符并限制 80 字符；作品 ID 缺失时回退为 `unknown`。

### 19.2 应用数据目录（`userData`）

| 文件                  | 作用                                           |
| --------------------- | ---------------------------------------------- |
| `config.json`         | 抓取、下载、过滤、主题、语言、代理、托盘等配置 |
| `pixiv_cookie.txt`    | 已保存的 Cookie（加密存储，旧明文自动迁移）    |
| `proxy_password.bin`  | 代理密码（加密存储）                           |
| `queue.json`          | 未完成下载任务快照                             |
| `history.json`        | 已下载文件元数据索引（供图库显示标题 / 作者）  |
| `viewHistory.json`    | 浏览记录                                       |
| `watchLater.json`     | 稍后看                                         |
| `oauth.json`          | App API 凭据（加密存储）                       |
| `pending-update.json` | 已下载待安装的更新标记                         |

- 配置、Cookie、队列等均采用原子写或容错读取，损坏时回落默认值。
- Cookie 仅脱敏显示，不写入日志。

### 19.3 备份与换电脑

1. 备份 `userData` 目录下的 `config.json`、`pixiv_cookie.txt`、`oauth.json`（如已连接 App API）、`viewHistory.json`、`watchLater.json`。
2. 需要继续未完成下载时一并备份 `queue.json`，并保持保存目录路径不变。
3. `history.json` 与 `*_downloads` 目录一起迁移，图库才能显示原有标题与作者。
4. 换机器后重新登录也能恢复；加密文件在系统重装或换用户后可能无法解密，此时重新登录即可。

## 20. 常见问题

### 下载按钮是灰的 / 点不了

- 未选中作品；
- 未配置 Cookie；
- 保存目录不是绝对路径；
- 文件名模板不合法（缺 `{id}` 或页码变量）。

### 抓取结果为空

依次检查：用户 ID、栏目（作者 / 收藏）、收藏类型（公开 / 私密）、标签、Cookie 是否有效。

### 收藏栏目选「私密」报错

私密收藏只有本人可见。填写他人用户 ID 时只能看公开收藏。

### 提示「私密收藏只有本人可见」

把收藏类型切回公开，或把用户 ID 改成当前登录账号（留空即可）。

### 下载很慢 / 频繁限流

- 调低「接口并发」「图片并发」，或适当增加最小间隔；
- 界面出现冷却提示属正常保护，冷却结束后自动继续，不计失败；
- 勾选较多作品时建议单个或少量任务并行，避免一次入队过多。

### 下载显示「已存在」但没有文件

检查保存目录是否被改动、文件是否被手动删除；重新扫描 / 刷新后再试。切换高清原图时，旧的常规图会被判为「未下载」并覆盖重下。

### 动图下载后不动

设置 →「动图格式」选 MP4 或 GIF 需要 ffmpeg；缺少时会退回 `.zip`。`.zip` 是帧压缩包，需自行解压或转码。

### 图库看不到刚下载的作品

- 确认保存目录正确；
- 图库会自动监听目录变化，通常 1 秒内刷新；也可点「重新扫描」；
- 旧版 `{标签}/{作者}/` 结构不会被识别，需要移到 `{作者ID}_{作者名}/illustration|manga|novel`。

### 图库作品标题显示「作品 12345」

`history.json` 索引缺失（例如手动复制了文件）。重新下载或保留原索引即可恢复标题与作者。

### 切换语言后列表还是旧语言

切换语言会重载页面；标题与标签译文来自接口，需要重新抓取 / 刷新列表才会换成新语言。

### 更新弹窗出现后点了「取消更新」

当前版本继续可用，退出时不会安装；下次启动仍可再次选择安装。

### 关闭窗口后程序不见了

默认收进托盘继续下载。托盘菜单「显示主窗口」或再次双击桌面图标即可叫回；如不需要后台运行，可在设置中关闭「关闭窗口时收进托盘」。

### App API 凭据失效

设置 → App API 凭据 → 重新「通过 pixiv 登录获取」或导入新的 `refresh_token`。此问题不影响浏览与下载。

### 代理测试提示「已连通但 pixiv 拒绝请求」

代理链路正常，但 pixiv 对出口 IP 或请求头有风控。可更换出口节点或稍后重试。
