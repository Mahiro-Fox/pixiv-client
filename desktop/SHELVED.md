# 功能搁置清单

记录已评估、但当前版本暂不实现的功能，避免需求丢失，也方便后续排期。
已实现功能见 [REQUIREMENTS.md](./REQUIREMENTS.md)，本文件只收录未落地项。

## 搁置项

| 功能 | 优先级 | 搁置原因 | 后续前置条件 |
| --- | --- | --- | --- |
| 增量同步定时任务 | P2 | 需要常驻调度、错过执行补跑、失败通知等完整链路，当前手动「同步收藏夹 + 只同步未下载」已能满足日常增量备份 | 先稳定队列与限流；明确调度周期、应用未启动时是否补跑 |
| 单张图片 HTTP Range 断点续传 | P2 | 当前按「文件粒度」重下，单文件失败重试成本可接受 | 需要记录已下载字节、校验服务端是否支持 Range |
| 多任务并行下载 | P2 | 全局限流下并行收益有限，且会放大 429 风险 | 先实现任务级排队与优先级，再评估并发上限 |
| SQLite 下载历史库 | P2 | 已提供 `history.json` 元数据索引，当前规模足够 | 作品量增长到 JSON 解析明显变慢时再迁移 |
| 磁盘空间预检 | P3 | 下载前预估体积不准（原图尺寸差异大），收益有限 | 需要稳定的体积估算来源 |
| 应用内代理 / UA 设置 | P3 | 目前依赖系统代理与固定 UA，满足基本使用 | 支持 pac /  socks 代理与自定义 UA 后再做连通性测试 |
| 多账号 Cookie 切换 | P3 | 单账号场景为主，切换涉及凭据隔离与目录归属 | 需要账号维度的配置与收藏夹目录隔离 |
| 剪贴板监听作品链接 | P3 | 与批量备份主流程关联弱 | 需要链接解析与单作品下载入口 |
| 托盘运行与系统通知 | P3 | 桌面端当前为窗口前台使用 | 引入托盘菜单、通知权限与最小化策略 |
| 安装包分发与自动更新 | P3 | 尚未进入分发阶段 | 确定签名、更新源与灰度策略 |
| 关注画师批量同步 | P3 | 当前为单选一位画师后抓取 | 需要任务编排、失败隔离与进度聚合 |
| 排行榜等更多作品来源 | P3 | 作者标签与收藏夹已覆盖主要场景 | 新增来源适配层与对应筛选字段 |
| 失败项逐条手动重试 | P3 | 现有整批重试已能覆盖大多数失败 | 需要更细的任务状态机与去重策略 |
| 界面国际化（i18n） | P3 | 当前仅中文用户 | 抽取文案资源并统一日期/数字格式 |
